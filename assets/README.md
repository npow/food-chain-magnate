# Artwork sources

These files reproduce official *Food Chain Magnate* artwork by Splotter Spellen.
They were cropped from the game's official English rules PDF, published by
Splotter Con:

https://splottercon.com/wp-content/uploads/2023/07/FCM_Rules_EN_v3.pdf

- `food-chain-magnate-box.png`: game box cover from the components overview.
- `food-chain-magnate-masthead.png`: game masthead and diner illustration.
- `restaurant-*.png`: the five restaurant identity tiles from the components
  overview.
- `house-tile.png`: the original numbered house tile, including its engraving
  and garden gate.
- `drink-*.png`: the soft drink, beer, and lemonade wooden-piece silhouettes.

Game design: Jeroen Doumen and Joris Wiersinga. Graphic design: Ynze Moedt and
Iris de Haan. Food Chain Magnate and its artwork are © Splotter Spellen BV.
This is an unofficial fan-made digital adaptation.
